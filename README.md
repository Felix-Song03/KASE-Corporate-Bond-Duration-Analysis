# KASE Corporate Bond Duration Analysis

This repository contains the Python code, data, and supporting outputs used for the empirical analysis in my dissertation on the corporate bond issuer journey at the Kazakhstan Stock Exchange (KASE).

## Research Focus

The study examines **admission-to-commencement duration**, defined as the number of calendar days between a bond's admission to the KASE trade list and the start of trading.

The analysis investigates how bond and issuer characteristics are associated with the length of this duration.

## Method

The empirical analysis uses the **Cox proportional hazards model**.

The analysis includes:

- data cleaning and sample construction;
- conversion of issue volumes into KZT;
- log transformation and winsorisation of continuous variables;
- descriptive statistics;
- Pearson correlation and variance inflation factor (VIF) diagnostics;
- Kaplan–Meier survival analysis;
- Cox proportional hazards estimation with standard errors clustered by issuer;
- proportional hazards tests based on scaled Schoenfeld residuals using the Kaplan–Meier transformation of analysis time; and
- robustness analyses excluding private placements and durations exceeding three years.

## Data

The datasets used in this analysis are included in the `data` folder. Corporate bond and issuer information was compiled from publicly available sources, primarily the official website of the Kazakhstan Stock Exchange (KASE) and public issuer disclosures. Exchange-rate data were obtained from the National Bank of Kazakhstan. The data are provided to support the reproducibility of the analysis.

## Running the Analysis

Install the required Python packages:

```bash
pip install numpy pandas matplotlib lifelines openpyxl
```

Then run:

```bash
python KASE_Corporate_Bond_Cox_Analysis.py
```

The script reads the required input files from the `data` folder and creates the `outputs` folder automatically if it does not already exist.

## Outputs

The `outputs` folder contains the main tables and figures generated by the analysis, including:

- sample construction and descriptive statistics;
- duration distribution;
- winsorisation information;
- correlation and VIF diagnostics;
- Cox model coefficient estimates and model-fit statistics;
- proportional hazards test results;
- Kaplan–Meier survival plots; and
- scaled Schoenfeld residual plots.
